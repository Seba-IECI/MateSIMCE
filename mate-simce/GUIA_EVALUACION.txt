MateSIMCE — Preparación de evaluación, lunes 9 de noviembre de 2026

Ejecutar comandos desde mate-simce/ con Node.js 22.
El README principal y tests/README.md contienen los requisitos y la clasificación
exacta de las pruebas. Esta guía sustituye las instrucciones de octubre.

1. CALIDAD Y REGRESIONES LOCALES
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:node
npm.cmd run test:e2e:types
npm.cmd run build
node tests/check-browser-secrets.cjs

2. SERVIDOR — TERMINAL 1
npm.cmd run start -- --hostname 127.0.0.1 --port 3100
Esperar Ready. No iniciar otro servidor sobre el mismo puerto.

3. INTEGRACIÓN REAL — TERMINAL 2
$env:MATESIMCE_TEST_BASE_URL = 'http://127.0.0.1:3100'
npm.cmd run test:http
I3 e I4 demuestran listado y detalle positivos con Next.js y Supabase reales.
Sin credenciales I1-I4 se omiten; I0 solo prueba rechazos HTTP sin sesión.
La cuenta adulta y el proyecto aislado deben estar en .env.test.local.
No abrir ese archivo durante la presentación.

4. NAVEGADOR REAL — TERMINAL 2
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm.cmd run test:e2e -- --config baseUrl=http://127.0.0.1:3100
Autenticación, práctica y ensayo se prueban sin mocks de servidor.
Práctica y ensayo crean intentos únicamente en el entorno de pruebas.
Si existe un ensayo pendiente, conservarlo: la suite no lo finaliza para limpiar.
No ejecutar con cuentas de alumnos reales ni contra producción.

5. DEMOSTRACIÓN BREVE
- Login y dashboard; cuatro ejes, consejos y navegación directa.
- Práctica: pista previa, selección, corrección, explicación, reintento y diagnóstico.
- Ensayo: preparación, 12 preguntas, progreso, recarga, finalización y revisión.
- Administrador: usar una cuenta autorizada por separado; verificar publicación
  sin cambiar ejercicios durante la demostración. El alumno no accede a /admin.
- Logout y rechazo de acceso a rutas protegidas.
- Mostrar GitHub Actions y el historial del PR, sin exponer archivos de entorno.

6. ALCANCE
La aplicación Next.js incluye interfaz, Server Actions y rutas de servidor.
No hay un backend separado. Los resultados no son puntajes oficiales SIMCE.
El despliegue Vercel y la ejecución remota del workflow requieren evidencia propia.
No ejecutar schema.sql/seed.sql: describen un modelo anterior de participantes.
No importar de nuevo el banco ni modificar RLS, funciones SQL o datos históricos.
